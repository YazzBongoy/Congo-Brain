# IAGov — Référentiel RDC : économie publique, fiscalité et budget

Ce dossier constitue une base documentaire structurée pour alimenter IAGov et Hermes.
Il privilégie les sources institutionnelles congolaises, puis les sources FMI/Banque mondiale
pour la validation macroéconomique.

## Règle de provenance
Toute donnée quantitative doit conserver : source, document, URL, date de publication,
période de référence, unité, devise, statut et date d'ingestion.

## Statuts
OBSERVED, BUDGETED, FORECAST, ESTIMATE, REVISED, AUDITED, SYNTHETIC.

## Utilisation
Les documents ci-dessous sont des synthèses de travail. Les textes juridiques et données
numériques originales doivent être téléchargés depuis les sources officielles et conservés
dans un dépôt de données versionné avant utilisation en production.
