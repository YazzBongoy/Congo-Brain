# Banque Centrale du Congo

Séries à intégrer :
- inflation ;
- taux de change ;
- taux directeur ;
- finances publiques ;
- indicateurs monétaires et financiers.

Chaque observation doit comporter :
indicator_id, period, value, unit, currency, frequency, source, vintage_date.

Sources :
