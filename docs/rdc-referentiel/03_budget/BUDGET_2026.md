# Budget RDC — exercice 2026

Le Ministère du Budget publie pour 2026 les documents de loi de finances, le CBMT 2026-2028,
la déclaration sur les risques budgétaires, les projets annuels de performance, les dépenses
d'investissement public et un rapport sur les dépenses fiscales.

Lors de la recevabilité parlementaire du projet, le Ministère du Budget a communiqué un
montant de 59 021 milliards de FC pour le budget 2026.
