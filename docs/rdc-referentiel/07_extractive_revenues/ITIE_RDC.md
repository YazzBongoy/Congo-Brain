# Revenus extractifs

L'ITIE-RDC fournit des rapports et des données ouvertes sur les revenus fiscaux et non fiscaux,
paiements des entreprises, production, contrats et flux financiers du secteur extractif.

Les données ouvertes sont disponibles notamment en CSV, XLSX et JSON et une API publique est
proposée pour les mises à jour automatiques.

## Knowledge Graph
Production -> Export -> Company -> Contract -> Payment -> GovernmentRevenue
GovernmentRevenue -> Budget -> Program -> Project -> Beneficiary

Sources :
https://www.itierdc.net/rapports/
