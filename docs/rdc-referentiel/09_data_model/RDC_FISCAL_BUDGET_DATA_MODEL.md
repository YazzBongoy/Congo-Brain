# Modèle de données fiscalo-budgétaire

## Dimensions
Temps, territoire, institution, budget, fiscalité, macroéconomie et gouvernance.

## Entités principales
FiscalYear, Province, ETD, Institution, Ministry, PublicEnterprise, BudgetLaw,
BudgetProgram, Appropriation, Commitment, Liquidation, Payment, TaxType, Taxpayer,
TaxBase, TaxRate, TaxReturn, TaxAssessment, TaxPayment, TaxExemption, Indicator,
Observation, Forecast, Scenario, Audit, Finding, Recommendation, ProcurementContract.

## Provenance obligatoire
source_id, source_document, source_url, publication_date, reference_period, unit,
currency, status, confidence, ingestion_timestamp.
