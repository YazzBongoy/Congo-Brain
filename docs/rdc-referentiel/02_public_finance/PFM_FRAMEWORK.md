# Finances publiques

La loi n°11/011 du 13 juillet 2011 relative aux finances publiques est une référence
structurante du modèle IAGov.

## Cycle à modéliser
Préparation -> Adoption -> Exécution -> Contrôle -> Reddition des comptes.

## Entités
BudgetLaw, BudgetProgram, Appropriation, Commitment, Liquidation, Payment,
AccountingEntry, Audit, AccountabilityReport.
