# Netsweeper — RDC / Digital Transformation

Documents reçus du partenaire Netsweeper pour le projet Congo-Brain.

- `netsweeper_digital_transformation_congo_drc.pdf` — « Digital Transformation Congo DRC, Dynamic Last Mile Compliance Execution » (EN, avril 2025). Pitch global : NS Enforce (blocage e-commerce/gambling non conforme), NS Clear (collecte TVA e-commerce/Mobile Money), sortie de la liste grise GAFI, AI-SCALE, cas Indonésie.
- `NS_Clear_NS_Enforce_RDC_juillet2026.pdf` — « Transformation numérique et souveraineté fiscale » (FR, juillet 2026). Version RDC : contexte (Plan National du Numérique, ADN, ARPTC, DGI), enjeux, architecture NS Clear & NS Enforce, GAFI/GABAC (23/23 actions, sortie possible octobre 2026), feuille de route 4 phases. Contact RDC : Oscar Djilo.
